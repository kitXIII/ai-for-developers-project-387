# Бюджет запусков агента по истории Actions

Status: accepted

Бюджет — три допущенные команды человека на один PR-тред, включая отмены, таймауты и Re-run;
отказы, `skipped` и `action_required` не считаются. Счётчик берётся из истории Actions: номер
треда пишется в `run-name` (`opencode #<N>`) и попадает в `display_title`, а единица — attempt,
в котором job агента реально стартовал. Комментарий или файл в репозитории не годятся: токен
агента может их переписать, а история Actions доступна только на чтение (`actions: read`) и не
переписывается токеном с `Issues: write`. Проверка идёт до checkout и вызова модели отдельным
job; причина отказа публикуется без модели. Решение принято по итогам research
[#48](https://github.com/kitXIII/ai-for-developers-project-387/issues/48).
